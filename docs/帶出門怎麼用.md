# 帶著 iPad／手機出門怎麼用

## 前提（你的實際情況）

- **所有資料都在家裡那台電腦上**（思考地圖、字幕、板書快照、看板資料、進度紀錄）
- **家裡沒有網路**，只有手機熱點
- **影片在 F 槽外接硬碟**，跟你一起帶出門
- 咖啡廳只有 iPad ＋ 手機 ＋ 硬碟，**沒有電腦**

手機熱點本身就是一個區網——即使不能上網，電腦和 iPad 連上同一個熱點就能互通。

---

## 第一次：兩個動作，做完就不用再管

**0. 先裝憑證**（只做一次）——見 [iPad憑證安裝.md](iPad憑證安裝.md)

沒裝的話離線功能不會啟用：iOS 只在 https 或 localhost 下提供 Service Worker，
`http://` 配區網 IP 兩者都不是。這是規格限制，純 http 上無解。

**1. 在 iPad 開這個網址**（熱點開著，電腦和 iPad 連同一個熱點）

```
https://172.20.10.3:8796/?k=40mqHhpGzgig
```

注意是 **https** 和 **8796**。8795 那個 http 埠留給電腦自己用，
以及讓 iPad 下載憑證。

通行碼就是網址裡那串 `40mqHhpGzgig`，**已經帶在網址上了，不用另外輸入**。
過一次之後這台裝置就記住（cookie 存一年），以後直接開
`http://172.20.10.3:8795/` 即可。

**裝置管理**：每台用 `?k=` 登入過的裝置，伺服器都發它自己的一張識別證。
借朋友的平板登入也沒關係——**新裝置預設唯讀**：教材照看，但勾的進度不會寫回
你的真實紀錄。要讓某台裝置能回寫（例如你自己的新 iPad），在家用電腦開
`http://localhost:8795/admin`（測試第二實例則是 `:8797/admin`；這頁只有電腦本機開得了），
幫它取個名、按「升級信任」即可；不認得的裝置就按踢除，它下次連線得重新輸入通行碼。

> 如果哪天看到 **8797/8798** 這組埠：那是測試新版用的第二實例，進度寫
> 在獨立的 `progress-dev.json`，不碰真實紀錄。平常出門用的永遠是 8795/8796。

忘了或換過通行碼，就看 `istudy-private-backup\data\server_key.txt`，
也印在 `reports\media_server.log` 最後幾行。若是打錯進不去，
「需要通行碼」那頁有輸入框可以直接貼。

> 熱點每次重連 IP 可能會變，開頭一定是 `172.20.10.`。
> 伺服器開機會自動啟動；沒跑的話雙擊 `啟動` 資料夾裡的 `feb-media-server.vbs`。

**2. Safari 分享選單 →「加入主畫面」**

之後都從主畫面的圖示開，才有全螢幕、無網址列，離線也開得起來。

**做完這兩件事就結束了。** 沒有第三步。

---

## 之後：什麼都不用按

打開 App，只要連得到電腦，它會自己在背景把教材補進這台裝置。
「硬碟與離線」收納選單裡的狀態燈會說結果（一切正常時外層不顯示燈，點開選單看）：

| 狀態燈 | 意思 |
|---|---|
| 🟢 **離線就緒 502** | 可以帶出門了 |
| 🟡 **補檔 120/380** | 正在補，等它跑完 |
| 🔴 **離線缺 38** | 連不到電腦。回家連上熱點打開 App 就會自動補 |

只補快取裡缺的，所以第二次之後幾乎是瞬間完成。想立刻重新檢查就點它一下。

備妥的內容約 100MB：思考地圖、字幕、**板書快照 251 張**、
**KaTeX 公式字型 20 個**、看板資料、21 份考古題分析、全文搜尋索引。
**不含影片**。

---

## 在外面：教材直接讀，影片要選一次資料夾

教材已經在裝置上了，斷網照樣開。影片因為太大不進快取，改從硬碟直接播：

讀書模式上排 → **📁 連結硬碟** → 選 **`istudy-backup`** 那一層（不是裡面的子資料夾）。

選完會顯示「已連結 N 支・對上課表 M 支」。原本標「未下載」的集數會變成
可以點的，尾巴標示「硬碟」，點下去直接播，可以拖曳快轉。

**兩件要先知道的事：**

1. **資料夾叫 `istudy-backup`，不叫「偉文」**。它在 F 槽最外層，
   但那層還有大約 250 個零散的照片和影片檔，要往下捲一段才看得到。
2. **重新整理後要再選一次**。這是瀏覽器的安全限制（網頁不能記住硬碟權限），
   一次點擊而已。iOS Safari 沒有 `navigator.storage`，影片也沒辦法預先存進裝置。

目前 101 支影片裡 **91 支對得上課表章節**。

離線時可以做的事：讀思考地圖（比較表、公式卡、決策樹、題型索引、錯誤對照、
板書快照）、開兩張**作戰地圖**（頂欄「線代地圖／工數地圖」，跟程式殼一起
預存，斷網照開）、做**今日複習**（工作台那條「RV · 今日複習」，到期卡離線
照樣抽）、進度落後就按工具列的**重排**（原本獨立的 replan 頁已併進來，斷網
也能算）、看衝刺看板、勾完成、記錯題、標看過、全文搜尋逐字稿。

## 回家：自動同步回電腦

回到家、連上熱點、打開 App，**開站 1.5 秒後會自動同步一次**。
你在外面勾的完成、記的錯題、標的看過、看到哪裡，全部會合併回電腦。

合併規則（不是整包覆蓋，所以兩邊的紀錄都不會被洗掉）：

| 資料 | 合併方式 |
|---|---|
| 看過標記、章節完成 | 取聯集，日期留較早的 |
| 錯題次數 | 取較大值 |
| 播放位置 | 留較新的；同日則留看得比較遠的 |
| 目標校系 | 取聯集 |
| 今日複習卡紀錄 | 逐筆合併，兩邊都留 |

進度存在電腦的 `istudy-private-backup\data\progress.json`。

## 疑難排解

**狀態燈一直是「離線：未就緒」**
- 一定要用 Safari，而且要從**主畫面圖示**開（不是 Safari 分頁）
- 其他瀏覽器多半沒有離線功能

**背景改了沒反應**
- 設定裡的「版面」如果是「!Boring 白」，讀書模式會強制白底把背景整個蓋掉
- 設定面板會直接提示，按「切回氛圍」即可

**沒接硬碟卻能看影片？**
- 那是硬碟插在電腦上、透過熱點串流回來的，不是 bug
- 但硬碟拔走帶出門後這條路就斷了，要改用「📁 連結硬碟」

**iPad 連不上**
- 確認兩台都在同一個熱點
- IP 變了？看 `media_server.log` 最新那行
- 電腦防火牆可能擋 8795，第一次連要允許

**影片播放卡頓**

先看讀書模式上排有沒有一顆黃色的 **⚠ 影片無法快轉**。有的話就是這個原因：
開站當下媒體伺服器還沒起來（開機自啟有時序），影片退回了不支援 Range 的
來源——不能拖曳快轉，而且每次播放都要從頭下載整支（實測 489MB 起跳），
播放全程都會卡。

現在會自己修：伺服器一回來，4 秒內自動切回可拖曳的來源，按鈕消失。
等不及就點那顆按鈕立刻重試。**看不到那顆按鈕就不是這個原因。**

修過的另外兩個：
- `localhost` 走 IPv6 導致每次連線多花 0.2 秒（改綁雙協定 `::`）
- 伺服器只講 HTTP/1.0，每要一段影片就重建一次連線；iPad 走 8796 還要再加
  一次完整 TLS 握手。已改成 HTTP/1.1 持久連線，同一條連線可以連續要好幾段。

還要量的話：`curl -o nul -w "%{time_connect}" http://localhost:8795/state.json`
正常是 0.001 秒等級。

**改了網站卻看不到更新**
- 伺服器現在對 html/js/css/json 都送 `no-cache`，一般不會再發生
- 真的卡住就改 `sw.js` 的 `VER` 版本號，或 Safari 設定 → 清除網站資料
