# iPad 安裝憑證（只做一次，之後永遠不用再碰）

## 為什麼非做不可

iOS 只在「安全連線」下提供離線功能（Service Worker）。規格上只有兩種算安全：
**https**，或 **localhost**。`http://172.20.10.3` 這種區網 IP 兩者都不是，
所以 Safari 根本不提供離線功能——這不是設定問題，純 http 上無解。

家裡沒有網際網路也可以跑 https，只是憑證得自己簽，iPad 要信任一次。

---

## 四個步驟

**1. 用 Safari 開這個網址下載憑證**

```
http://172.20.10.3:8795/ca.crt
```

會跳出「此網站正嘗試下載一個設定描述檔」→ 按**允許**。

**2. 安裝描述檔**

設定 → 最上面會出現「**已下載描述檔**」→ 點它 → 右上角**安裝** →
輸入螢幕鎖定密碼 → 再按一次**安裝**。

**3. 開啟完全信任**（漏了這步等於沒裝）

設定 → 一般 → 關於 → 拉到最底 → **憑證信任設定** →
把「**Feb 備考平台（區網）**」的開關打開 → 確定。

**4. 改用 https 網址，重新加入主畫面**

```
https://172.20.10.3:8796/?k=40mqHhpGzgig
```

注意是 **https** 和 **8796**，跟之前的 http／8795 不一樣。
進去之後分享 →「加入主畫面」。**舊的那個圖示可以刪掉了。**

---

## 怎麼確認成功

進讀書模式看狀態燈：

- 🟢 **離線就緒 443** → 成功，可以帶出門
- 🔴 **離線：要用 https** → 還開在舊的 http 網址上
- 🔴 **離線：未安裝** → 憑證裝了但第 3 步的「完全信任」沒開

---

## 這張憑證的安全性

刻意只簽**一張**自簽憑證，沒有另外做私有 CA。差別在於：

- 私有 CA：iPad 會信任「這個 CA 簽發的任何網站」——範圍太大
- 單張自簽憑證：iPad 只信任**這一張**，只對 `172.20.10.x:8796` 有效

私鑰只在電腦的 `istudy-private-backup\data\server.key`，沒有離開過這台機器。

涵蓋位址：`172.20.10.1`～`172.20.10.14`（iPhone 熱點固定發這一段，
所以熱點重連換了 IP 也不必重簽）＋ 本機所有 IPv4 ＋ `127.0.0.1`。
效期到 **2028-10-31**。

要換網段或重簽：

```bash
python tools/make_cert.py --force
```

重簽之後 iPad 上要重裝一次。

---

## 兩個埠的分工

| 埠 | 協定 | 用途 |
|---|---|---|
| 8795 | http | 電腦自己用；提供 `/ca.crt` 下載 |
| 8796 | https | iPad／手機用，離線功能只在這個上面成立 |

（測試新版的第二實例用 **8797/8798**，分工相同；憑證同一張就涵蓋，不用重裝。）

`/ca.crt` 必須走 http 而且不擋通行碼——沒憑證就連不上 https，
連不上 https 就下載不到憑證，會變成死結。
