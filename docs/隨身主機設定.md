# 隨身主機：樹莓派 + 硬碟，咖啡廳也能原畫質看課

## 你只要做三件事

檔案我已經全部放進硬碟了，不用自己搬。

### 1. 把硬碟和行動電源接上 Pi，開機

### 2. 在 Pi 上打開終端機，貼這一行

```bash
sudo bash "$(find /media -name setup_pi.sh -path '*feb-pi*' 2>/dev/null | head -1)"
```

這行會自己去找腳本在哪，硬碟叫什麼名字、掛在哪個位置都不影響
（硬碟名稱含空格也不會出錯）。

> 若出現「找不到檔案」，先確認硬碟真的掛起來了：`ls /media/*/`
> 應該要看得到 `Crucial X6` 之類的名字，進去有 `feb-pi` 和 `istudy-backup` 兩個資料夾。

腳本會自己做完：開 USB 供電、裝 exFAT、設定硬碟自動掛載、把程式複製到 Pi、
裝開機自啟服務。跑完會印出 iPad 要開的網址。

### 3. 重開機，然後在 iPad 打開網址

```bash
sudo reboot
```

網址長這樣（腳本會印出正確的 IP）：

```
https://172.20.10.x:8796/?k=40mqHhpGzgig
```

進去後分享 →「加入主畫面」。**憑證不用重裝**，iPad 上信任過的那張直接沿用。

---

以下是原理與疑難排解，平常不用看。

## 為什麼是這個做法

iPad 的 Safari 從外接硬碟讀檔案時**一定會把整支影片複製進 iPad**（見
[咖啡廳怎麼用VLC.md](咖啡廳怎麼用VLC.md)），iPad 只剩 3GB、課程共 86GB，走不通。
VLC 雖然能直接讀硬碟，卻換來：思考地圖不能點時間戳跳轉、看到哪不會自動記錄、
字幕重點反白消失——等於把整套教材退化成純播放器。

改讓**樹莓派接硬碟、在旁邊當伺服器**，iPad 連熱點看，就跟在家用電腦時一樣：
原畫質、可拖曳快轉、思考地圖點了直接跳、進度自動記錄。硬碟不用插 iPad。

```
   行動電源 ── 樹莓派 ── USB ── 你的硬碟（86GB 課程）
                  │
              iPhone 熱點
                  │
                iPad（Safari 開網頁，跟在家一樣）
```

## 你這台 Pi 3B 夠不夠？夠，而且餘裕很大

課程影片是 720p、**0.74 Mbps**（實測）。對照 Pi 3B 各項上限：

| 環節 | 上限 | 餘裕 |
|---|---|---|
| USB 2.0 讀硬碟 | 35 MB/s | 376 倍 |
| 內建 WiFi (2.4GHz) | 約 40 Mbps | 54 倍 |
| iPhone 熱點 | 約 30 Mbps | 40 倍 |

最弱的一環都還有 40 倍餘裕。

## 真正要注意的只有供電

Pi 3B 全部 USB 埠**共享約 1.2A**，行動硬碟啟動瞬間可能拉到 0.9A。
電不夠的症狀是「播到一半硬碟突然消失」，不是當機，很容易誤判成程式壞掉。

- 行動電源選 **5V/2.5A 以上**，並確認支援「邊充邊放」
- 設定腳本已自動開啟 `max_usb_current=1`
- 若仍會斷線，改接**帶獨立供電的 USB Hub**，硬碟插 Hub 上

## 每次出門的流程

1. 開 iPhone 熱點
2. Pi 接上硬碟與行動電源，開機（約 40 秒，不用按任何東西）
3. iPad 從主畫面圖示打開

沒有第四步。

## 出問題怎麼查

**iPad 連不上**

先確認兩台都在同一個熱點。再看 Pi 的服務有沒有活著：

```bash
systemctl status feb-media
```

**影片播到一半停住 / 硬碟消失**

九成是供電。看核心有沒有記錄到掉電壓：

```bash
dmesg | grep -i "under-voltage\|usb disconnect"
```

**https 跳憑證警告**

代表 Pi 拿到的 IP 不在 `172.20.10.x`（例如接了家用 WiFi）。
改連 iPhone 熱點，或重簽憑證：

```bash
python3 ~/feb/istudy-private-backup/tools/make_cert.py --force
```

重簽後 iPad 要重裝一次憑證（步驟見 [iPad憑證安裝.md](iPad憑證安裝.md)）。

**想看伺服器在做什麼**

```bash
journalctl -u feb-media -f
```

## 進度會不會亂掉？不會，但要知道它怎麼運作

進度**主要存在 iPad 自己身上**（瀏覽器的本機儲存），伺服器那份是備份與合併用。
每次連上伺服器時，是把 iPad 這份送過去合併，再把合併結果寫回 iPad。

| 情境 | 結果 |
|---|---|
| 在咖啡廳用 Pi 看課 | 進度記在 iPad，同時備份到 Pi |
| 回家用**同一台 iPad** 開電腦的網站 | iPad 把外面的進度帶回來，跟電腦那份合併 |
| 回家改用**電腦**看 | 電腦不知道 iPad 在外面做了什麼，要先用 iPad 開一次 |

**要點：回家後先用 iPad 開一次網站**（連電腦的熱點），進度才會回到電腦。
開站 1.5 秒後自動同步，不用按任何按鈕。

合併是逐欄位處理（已實測驗證），兩邊紀錄都不會被洗掉：

| 資料 | 合併方式 |
|---|---|
| 看過標記、章節完成 | 取聯集，日期留較早的 |
| 錯題次數 | 取較大值 |
| 播放位置 | 留較新的；同日則留看得比較遠的 |
| 目標校系 | 取聯集 |

## 之後網站有更新怎麼辦

電腦上改完後，把 `grad-exam-hub/site` 與 `istudy-private-backup/tools`
複製到硬碟的 `feb-pi` 對應位置，接上 Pi 再跑一次設定腳本即可（可重複執行）。
