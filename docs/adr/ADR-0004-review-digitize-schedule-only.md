# ADR-0004 複習排程數位化，手寫練習留紙本

日期：2026-08-31　狀態：已決

## 決策
間隔重複的「排程」進讀書工作台（今日複習條：到期卡號＋GoodNotes 頁碼＋pass/A/B/C），
「練習」本身留在紙本/GoodNotes。review-sheet.html（A4 排程紙）退役。

## 理由
14 天紙本試跑結論＝(b) 斷斷續續：練習有做，排程表常忘了看。
紙本爛的正是日期運算、到期提醒、失敗碼統計——全是機器的強項；
紙本好的是手寫提取練習——數位化它是自殺。

## 規格要點
排程律法照 review-sheet 原文：+3/+14/+28、距考 60/30 天壓縮、失敗重設、
「晚了不補、不積複習債」。資料模型（權威版，與 T07 一致）：`feb-review-v1 = {cards:[{id, subject, page, createdAt, history:[{date, result}]}]}`；
/sync 合併：cards 按 id 聯集、history 聯集去重——**合併邏輯住在伺服器端** `serve_media.py merge_progress()`，見 T07。

## 詮釋裁決（T07，2026-08-31）
「失敗重設回 +3」與距考壓縮條款合讀＝**梯級歸零到當前檔位的梯首**
（基本檔 +3、≤60 天檔 +3、≤30 天檔 +2）。否則 30 天內失敗的卡會排得比新卡晚，
自相矛盾。20 條單元測試以此語意為準（tests/review-core.test.js #8–9）。
