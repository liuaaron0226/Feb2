# ADR-0003 戰功子系統只換皮不換骨

日期：2026-08-31　狀態：已決

## 決策
以下子系統的邏輯原樣搬移，僅替換視覺層與 DOM 結構外皮：
自製播放器（vseek/章節軌/倍速/字幕/PiP）、SW 離線鏈（audit/prefetch/狀態燈）、
/sync 逐欄位合併、外接硬碟 blob 播放、隨播面板、rlog 遠端診斷、媒體三層 fallback。

## 紀律（新立，全站適用）
1. **狀態永遠不存在 DOM 裡**——重繪即丟的教訓（git 38ab749）
2. **永不重繪的元素**（如 `#diskPick` file input）在拆分後保持 body 直屬（git 9e545c1）
3. 資料快取與程式版號分離（git 68b598f「是我自己把使用者的教材快取砍光的」）

## 驗收
每張換皮票都以原版行為為基準：桌面 smoke ＋ `_febSelfCheck()` 通過。
