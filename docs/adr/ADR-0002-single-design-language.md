# ADR-0002 單一設計語言：氛圍語系存活，!Boring 刪除

日期：2026-08-31　狀態：已決

## 決策
五套並存的視覺 token（index 深色玻璃 / !Boring 白皮 / 地圖頁 / replan 金色 / 印刷對）
收斂為一套語意 token 系統。!Boring 皮膚與 `feb-skin` 切換整個刪除；氛圍語系是存活者。

## 理由
- 使用者實際讀書時用氛圍版；!Boring 是捨不得刪的死代碼（~120 行覆寫選擇器）
- 「備考的人不該每天做風格決策」——刪掉切換點本身就是 UX 改善

## 設計裁量（授權給 Claude）
強度隨模式收放：home 保留氛圍門面（時鐘＋背景主題），study 安靜化
（背景近無、玻璃收斂、動效只留功能回饋），exam 居中。省電機制隨之大幅簡化。
既有的量化紀律（字階五級、按鈕三高三型、圓角三級）是萃取起點，不是推翻對象。

## 方向判定（2026-08-31，T01）

三方向變體（A 夜航儀表／B 湖面玻璃／C 藍曬作戰圖）瀏覽器實渲染比較後，使用者裁定：

> 「我覺得可以把A跟B融合，我覺得A資訊的呈現方式我很喜歡不過缺少湖面玻璃的效果。」

**定案＝A×B 融合**：資訊層全取 A（mono 儀表讀數、眉標紀律、D-154 倒數尺簽名、
學科色去飽和作結構線），表面層全取 B（液態玻璃 7%/14%＋內光、aurora 氛圍場、
凝結進場、液態漣漪）。C 不參與融合。強度儀（home 100%／exam 中／study aurora≈8%）
以 B 的實作機制為準。ember 雙階（#C25E2E 燒的東西／#E07840 可讀文字）採 A 的對比解法。
變體檔存檔於 .scratch/redesign/direction/ 供考古。

## 背景主題存活清單（2026-08-31，T01，使用者拍板）

> 「描圖紙、黑板是我最喜歡的兩個風格，其他都可以刪除」

**存活**：aurora 氛圍場（融合方向的基底層，非主題選項）、描圖紙 vellum（亮，
繼續驅動 body.lt 亮色路徑）、黑板 chalk（暗）、自訂上傳（T03 既定範圍）。
**退役**：方格紙 graph、水磨石 terrazzo、藍曬 blueprint、曜黑 onyx。
feb-bg 存到退役主題舊值時 fallback 到預設（T03 驗收既有條款）。

## 去框化原則（2026-08-31，T01，使用者回饋）

> 「你使用太多框框了，我希望可以多增加一些創意」

**框是例外，不是預設。** 結構優先用字階、留白、縮排、單一髮絲線、色彩與 z 深度
（亮度/模糊）表達；四邊框＋圓角的面板保留給真正「浮起」的東西（modal、播放器
控制列、今日複習條這類 overlay）。頁面內容直接活在 aurora 場上。簽名元素允許
出血（tick-rail 貫穿全寬）；表格用行線不用外框；section 分隔＝眉標＋一條線或純留白。
此原則入 design-system.html 的「規 RULES」，T03–T09 一體適用。

## 修訂三（2026-09-01 晚，使用者裁定）
1. **配色收斂**：15 組合中僅「描圖紙×餘燼」「夜湖×松青」獲認可——改為**每地面配定製預設調色**
   （切地面自動帶入對味調色，仍可手動覆蓋）；弱地面（墨水/牛皮紙/黑板）重造材質identity。
2. **背景要材質多樣**：「背景設計風格都很單一，沒有不同的元素主題以及材質」——每個地面
   必須有自己的材質語彙與元素主題，不是換色而已。
3. **讀書模式動效鬆綁**：「讀書模式的動畫似乎有點少，可以再加一些」——quiet 檔開放
   「gentle ambient」白名單（慢環境動效循環）＋互動/轉場動效全面增豐；「循環播放」
   ＝環境動效以 loop 為預設。S5 硬檢由「study 零無限動畫」修訂為
   「study 僅白名單 ambient loop（全部吃 --ambient-play 且 reduced-motion 全滅），
   互動動效 60fps transform/opacity only」。
