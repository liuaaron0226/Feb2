# ADR-0007 裝置管理：localhost 即管理者、訪客預設唯讀

日期：2026-08-31　狀態：已決（使用者於對話中核可推薦包）

## 背景
朋友將以平板登入。原授權模型是一把共享通行碼——踢不掉單一裝置，
且任何登入裝置的 /sync 寫入都會聯集進真實備考進度（事後洗不掉）。
此為功能凍結（SPEC 非目標）之明文例外，由使用者解凍。

## 決策
1. **每裝置專屬 session**：通行碼登入時發裝置 token（記名稱/UA/IP/最後活動/模式）
2. **管理者＝localhost**：管理台只回應 127.0.0.1／::1——人坐在家用電腦前即管理者，
   零帳號、零新密碼
3. **訪客預設唯讀**：新裝置 mode=readonly，伺服器拒其 POST /sync；
   管理台可取名、升級 trusted、一鍵踢除（token 作廢）
4. 內容權限分級**不做**（訪客看得到頁面內容；只隔離寫入）
