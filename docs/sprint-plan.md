## 排序原則：熱區決定「念什麼」，課本決定「什麼順序」

這兩件事是正交的，不要混為一談：

- **涵蓋範圍**由十年考古題熱區決定——跳過只考 1% 的章節（PDE、複變、數位電子）。
- **學習順序**由先備知識決定——照課本／授課的依賴鏈，基礎先行。

2026-08-16 依此原則修正過兩處排序錯誤：

1. **補上電子學第零章（基本電路學）**：戴維寧等效、重疊定理、負載效應是分析所有
   放大器電路的工具，原本漏收（115暑電子 01、02）。
2. **差動與電流源 W4 → W3**：課本與偉文授課序都是「電流鏡／差動 → 頻率響應 →
   OP → 回授」，原本把差動排到最後，等於先學進階分析再補基本組態。

已驗證的依賴鏈：

- **線代**：矩陣／行列式 → 向量空間／四大子空間 → 特徵值／對角化 → 內積／正交 → SVD／二次型
- **電子學**：基本電路學 → 二極體 → BJT 偏壓 → BJT 小訊號 → MOSFET 特性 →
  MOSFET 小訊號／CMOS → 差動／電流源 → 頻率響應 → OP → 回授與穩定度
- **工數**：ODE 一階 → 高階 → 聯立（需要 W2 的特徵值）→ 拉氏 → 傅立葉
- **控制（9/13 起）**：建模 → 時域 → Routh → 根軌跡 → 頻域 → 控制器設計 → 狀態空間

**跨科依賴**：控制系統的轉移函數建立在**拉氏轉換**上，而拉氏排在 W4（9/6–9/12），
控制 9/13 接棒——順序剛好接得上，不要把拉氏往後挪。

## 每章學習迴圈（固定走法）

1. 看該章對應影片集數（1.5–2x，只看熱區章，不整套看）
2. 講義例題跟著手算（看懂 ≠ 會算，一定要動筆）
3. **當天**寫該章考古題 2–3 題（站上題庫按熱力表挑有考該章的年份）
4. 卡住 → 回影片對應段落；錯的記進錯題本（章節＋錯因一句話）

每天 4.5h 建議切法：電子學 2h ＋ 工數 2h ＋ 0.5h 複習昨日錯題。多益 30 分鐘（通勤／睡前，背單字＋聽力）。

## 四週日程

### W1（8/16–8/22）：地基（26h）
- 電子學：**基本電路學（第零章，~2h）**→ 二極體電路（~6h）→ BJT 直流偏壓（~6h）
- 工數：線代——矩陣運算與行列式（~4h）→ 向量空間與四大子空間（~8h）
- 週日（8/22）：半天複習＋每科單章混合小測

> **實測：偉文一堂課約 169 分鐘（近 3 小時）**，2 倍速看完約 85 分鐘。
> 因此不要「整堂看完再做題」——每講完一個定理＋例題就暫停，去寫對應考古題，
> 再回頭看下一段。章節時數（如線代矩陣 4h）指的是「看＋做題」的總投入，
> 不是影片長度：約略是 2 倍速看 1.5 小時 ＋ 做題 2.5 小時。

### W2（8/23–8/29）：最大板塊（25h）
- 電子學：BJT 小訊號放大器（~7h）→ MOSFET 特性與偏壓（~6h）
- 工數：線代——特徵值與對角化（~7h）→ 內積空間與正交（~5h）
- 週日（8/29）：複習＋小測（線代此時應能寫成大工科線代考古題）

### W3（8/30–9/5）：衝刺主峰（27h）
- 電子學：MOSFET 小訊號＋CMOS（~8h）→ **差動與電流源（~3h）**→ 頻率響應（~6h）
- 工數：ODE——一階（~4h）→ 高階線性（~6h）
- 週日（9/5）：複習＋小測

### W4（9/6–9/12）：收攏第一輪（25h）
- 電子學：運算放大器（~5h）→ 回授與穩定度（~4h）
- 工數：ODE 聯立與應用（~3h）→ 拉氏轉換（~6h）→ 傅立葉級數與轉換（~5h）＋ SVD 補完（~2h）
- **9/12 驗收**：限時各寫一份整卷——電子學用中央卷、工數用台聯大工數 C 卷。目標不是 90，是「每題都知道在考哪章、一半以上能動筆」
