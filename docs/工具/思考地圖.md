# 思考地圖（`tools/make_notes.py`）

替**已經有字幕**的課程影片產生「思考地圖」：AI 讀完整堂課的逐字稿，
不是寫摘要，而是**把這個章節重新教一次**。它用比較表、決策樹和公式卡當主要語言，
並用標準教科書補上老師快速帶過的地方。產出是影片旁的 `<影片名>.notes.json`，
網站播放器的右欄會把它渲染出來，裡面的時間戳一律可以點擊跳轉。

一次執行順便做四件副產品：

1. **勘誤**套回 `.vtt`，並累積到 `fixes.json`（勘誤飛輪，[自動生成字幕](自動生成字幕.md)會讀）
2. **重點時段**在 `.vtt` 裡用 `<c.key>` 標起來（網站用 `::cue(.key)` 上色）
3. 用 ffmpeg 抽**板書快照** `<影片名>.snap_<秒>.jpg`（每支最多 6 張）
4. 重建**全文搜尋索引** `search_index.json`（20 秒一窗，網站搜尋用）

---

## 認證：沒有金鑰

分析引擎是 **Claude Code CLI 的無頭模式**（`claude -p`），一支影片呼叫一次。
程式本身不讀、不存任何 API 金鑰，用的是 `claude` CLI 自己的登入狀態。
換電腦時先跑一次 `claude` 並完成登入即可。

模型和思考強度**寫死**在程式開頭：`claude-opus-5`、`xhigh`。
這批筆記是同一套複習素材，如果跟著全域設定漂移，就會默默變成半套 A 模型、半套 B 模型，
事後也分不出哪集是誰做的。每份產出的 `by` 欄位會記下實際用的模型。
要做 A/B 比較時用 `--model`、`--effort` 臨時覆寫。

## 環境需求

| 項目 | 說明 |
|---|---|
| `claude` CLI | 在 PATH 裡，已登入 |
| ffmpeg | 抽板書快照用 |
| Python | 3.11，只用標準函式庫 |
| 字幕 | 影片旁要先有 `.vtt`（沒有的會跳過） |
| 影片清單 | `F:\istudy-backup\state.json`（同[自動生成字幕](自動生成字幕.md)） |
| 衝刺課表 | `data/videos.json`、`data/sprint.json`：決定先做哪一週的課 |

## 流程

```
挑片：有 .vtt、還沒有 .notes.json、符合 --only 範圍
  │  依衝刺週序排（這兩週要看的先做）
  ▼
組 prompt：tools/notes_prompt.md 模板 ＋ 逐字稿（每行「秒數|句子」）
  ▼
claude -p --output-format stream-json（逾時 900 秒＋每萬字 250 秒，上限 1 小時）
  ▼
解析 JSON（容忍前後說明文字、``` 圍欄；第一次失敗會帶提示重問一次）
  ▼
validate：時間戳夾進片長、重點時段合併成不重疊、比較表欄列數對不上就丟掉
  ▼
lint：契約軟檢查，只警告不擋（節點太多、缺比較表、重點覆蓋率偏離 35~55%…）
  ▼
寫 .notes.json → 勘誤與重點套回 .vtt → 抽快照
  ▼
全部跑完：重建 search_index.json 與 fixes.json
```

## 用法

```
python tools/make_notes.py --limit 1 --only 115暑線代01          # 試產一支
python tools/make_notes.py --only-file tools/notes-scope-five.txt  # 照範圍檔補齊
python tools/make_notes.py --dry --only-file tools/notes-scope-five.txt  # 只列清單
python tools/make_notes.py --index-only                           # 只重建搜尋索引
```

| 參數 | 說明 |
|---|---|
| `--limit N` | 只做前 N 支 |
| `--only 字串` | 代號比對（逗號分隔多個） |
| `--only-file 檔案` | 從 UTF-8 檔讀範圍清單（逗號或換行分隔，`#` 開頭是註解） |
| `--force` | 已有 `.notes.json` 也重做 |
| `--dry` | 只列待產清單，不呼叫 claude |
| `--index-only` | 只重建全文搜尋索引 |
| `--model`、`--effort` | 臨時覆寫模型與思考強度 |

### 範圍檔 `tools/notes-scope-*.txt`

| 檔案 | 內容 |
|---|---|
| `notes-scope-five.txt` | 工數、線代、電子學（用科目字眼比對，新期別會自動涵蓋）；**週日排程只吃這份** |
| `notes-scope-elec-16-19.txt` | 電子學 16、19 兩支，一次性補做用 |
| `notes-scope-toeic.txt` | 多益，平常不在範圍內，要補時手動叫 |

範圍之所以放在檔案裡而不是寫在 bat 的命令列：中文參數在 cp950 主控台會被字碼頁改寫，
結果一支都比對不到；bat 又不能先 `chcp 65001`，因為切換碼頁後 cmd 重讀檔案會錯位吃字
（2026-09-05 實測，整行指令消失）。所以中文放進 UTF-8 檔案，bat 保持純 ASCII。

### 入口

- `補字幕與筆記.bat`：手動雙擊，先做字幕再做思考地圖
- `scripts/補思考地圖.bat`：只補思考地圖，做完上傳 Drive 並部署雲端站
- `scripts/週日保鮮.bat`：每週日 10:00 的排程工作（見 [`docs/自動化.md`](../自動化.md)）

日誌寫在 `F:\istudy-backup\notes.log`。

## 出錯時的行為

| 狀況 | 行為 |
|---|---|
| **額度用完**（429、rate limit、usage limit…） | 整批立刻停止，不會把剩下的每一支都跑成失敗。額度恢復後重跑就接續 |
| **回了合法 JSON 但內容是空的** | 不寫檔，原始輸出存成 `_rawnotes_<代號>_thin.txt`，這支下次重跑會再排進來 |
| **兩次都不是合法 JSON** | 兩份原始輸出存成 `_rawnotes_<代號>_1.txt`／`_2.txt` 供查驗 |
| 單支其他錯誤 | 記一行日誌，繼續做下一支 |

空結果之所以不寫檔：`validate()` 會把缺少的欄位補成空骨架，
如果照樣存檔，看板上會顯示「有思考地圖」，點進去卻什麼都沒有。

## `.notes.json` 結構

```jsonc
{
  "version": 1,
  "fixes":    [["誤寫", "正確"]],                 // 術語辨識錯字
  "chapters": [{"t": 0, "title": "開場與本集導覽"}],
  "keys":     [{"a": 1234, "b": 1450, "why": "為何是重點"}],   // 重點時段（秒）
  "snaps":    [{"t": 4021, "cap": "圖說"}],        // 板書快照時間點
  "map": {
    "tldr": ["本集重點一句話"],
    "flow": "graph TD ...",                       // mermaid 知識骨架
    "concepts": [{ "name": "…", "mermaid": "…", "svg": "…", "md": "…",
                   "sup": "〔補〕教科書補充", "trap": "…",
                   "formulas": [{"tex": "…", "name": "…", "when": "…"}],
                   "compare": {"title": "…", "cols": ["軸", "A", "B"], "rows": [["…", "…", "…"]]} }],
    "examples": [{"t": 4021, "tag": "…", "trigger": "…", "md": "…", "trap": "…", "snap": 4021}],
    "playbook": [{"trigger": "題目給了什麼", "method": "用哪招"}],
    "pitfalls": [{"wrong": "…", "right": "…", "why": "…"}]
  },
  "code": "115暑線代01", "dur": 7200, "by": "claude-opus-5/xhigh", "pv": 3
}
```

輸出規格（「律一～律六」、長度預算、mermaid 形狀與配色）完整寫在 `tools/notes_prompt.md`，
要調整筆記風格就改那份模板。

## 誰在用這些產出

- **播放器右欄**：`site/js/10-player.js` 渲染，marked＋KaTeX＋mermaid 懶載入（`site/vendor/`）
- **字幕重點上色**：`site/css/app.css` 的 `::cue(.key)`
- **全文搜尋**：`search_index.json`
- **作戰地圖**：`scripts/la-map/`、`scripts/me-map/` 把整科的 `.notes.json` 重組成單頁地圖

## 產出不進 repo

`.notes.json`、快照與搜尋索引都是課程內容的衍生物，和影片一起留在外接硬碟。
`.notes.json` 與 `*.snap_*.jpg` 另外列在 `.gitignore`，當作誤放進專案資料夾時的第二道保險。
