# 自動生成字幕（`tools/make_subs.py`）

替已下載的課程影片產生**繁體中文字幕**（`.vtt`），檔案直接放在影片旁邊，
網站播放器會自動掛上。

**不需要任何 API 金鑰。** 語音辨識是本機 GPU 跑的 faster-whisper，
不呼叫 OpenAI／Azure／Deepgram 或任何雲端服務，影片與聲音都不離開這台電腦。

---

## 流程

```
F:\istudy-backup\state.json（下載器產生的影片清單）
  │  篩出：已下載完成、檔案還在、旁邊還沒有 .vtt 的影片
  ▼
ffmpeg 抽音軌 → 16 kHz 單聲道，每 10 分鐘切一塊（相鄰兩塊重疊 5 秒）
  ▼
faster-whisper large-v3（CUDA、int8_float16、beam 1、VAD 濾靜音）
  ▼
OpenCC s2twp：Whisper 吐的簡體 → 臺灣正體與慣用詞
  ▼
套「勘誤飛輪」：fixes.json 裡同科目、兩支以上影片都提過的錯字替換
  ▼
<影片名>.vtt（先寫 .vtt.tmp 再換名，寫到一半中斷不會留下壞檔）
```

已經有 `.vtt` 的影片一律跳過，所以**隨時可以中斷，重跑就接續**。

## 環境需求

| 項目 | 說明 |
|---|---|
| 顯示卡 | NVIDIA GPU（實測 RTX 3060 6GB） |
| Python | 3.11 |
| 套件 | `pip install faster-whisper opencc-python-reimplemented numpy nvidia-cublas-cu12 nvidia-cudnn-cu12` |
| ffmpeg | 要在 PATH 裡 |
| 影片 | `F:\istudy-backup`（外接硬碟），清單在 `state.json` |

`state.json` 由下載器產生（`istudy-private-backup\tools\grab_istudy.py` 等，不在這個 repo），
每支影片一筆：`code`（集數代號）、`title`、`series`（科目／期別）、`path`、`sec`、`status`。

路徑寫死在程式開頭的 `OUT_ROOT`，換電腦或換硬碟代號要改這一行。

## 用法

```
python tools/make_subs.py --limit 1           # 先做一支試試
python tools/make_subs.py                     # 全部沒字幕的都做
python tools/make_subs.py --only 115春矩陣     # 只做代號含指定字串的（可用逗號列多個）
```

| 參數 | 預設 | 說明 |
|---|---|---|
| `--limit N` | 0（不限） | 只做前 N 支 |
| `--only 字串` | 全部 | 代號比對；會先拿掉講師標記 `(喻)` 與最後一集的 `-The End` 尾綴再比 |
| `--model` | `large-v3` | Whisper 模型 |
| `--beam` | 1 | beam size，見下方實測 |
| `--chunk-min` | 10 | 每塊音訊幾分鐘；0＝整支一次做（會吃數 GB 記憶體） |

平常不必手動跑，有兩個入口會呼叫它：

- `補字幕與筆記.bat`：手動雙擊，字幕做完接著做[思考地圖](思考地圖.md)
- `scripts/週日保鮮.bat`：每週日 10:00 的排程工作（見 [`docs/自動化.md`](../自動化.md)）

日誌寫在 `F:\istudy-backup\subs.log`。

## 設計取捨

**為什麼 beam 1、不用批次模式**（RTX 3060、large-v3 實測）：

| 設定 | 速度 | 結果 |
|---|---|---|
| 逐段 beam=1 | 7.7 倍實時，平均 1.4 秒一句 | **採用** |
| 逐段 beam=5 | 7.0 倍實時，平均 1.6 秒一句 | 品質差異不明顯 |
| 批次 batch=16 | 22.6 倍實時 | 30 秒併成一段、會重複幻覺，不能當字幕 |

**為什麼要切塊**：整支影片直接丟給 faster-whisper 時，VAD 會對全長算一次頻譜，
157 分鐘的課需要 2.1 GiB 連續記憶體。電腦同時在下載和做思考地圖時會配置不到，
2026-09-06 晚上因此連續失敗了 9 支。切成 10 分鐘一塊後，每塊只要幾百 MB；
重疊 5 秒是為了不把句子切在交界處，重疊區重複的句子會丟掉。

**為什麼勘誤要兩票**：`fixes.json` 由[思考地圖](思考地圖.md)分析影片時累積，
按科目分桶（「志工→資工」在線代裡是對的，套到多益就是災難）。
只有**兩支以上影片各自提出**的替換才會生效。踩過的例子：某一支影片提了「反正→反證」，
但「反正」是老師的口頭禪、全庫出現 85 次，無條件替換會悄悄毀掉字幕。
