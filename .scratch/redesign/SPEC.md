# SPEC — Feb 平台全面重設計

> 本文界定**要解決什麼**，不含實作。實作拆解見 `issues/`。決策依據見 `../../docs/adr/`。

## 問題陳述

Feb 是一套運作中的個人備考作業系統，但它是三個月手養出來的：

1. **五套視覺語言各自為政**——index 深色玻璃、!Boring 白皮、兩張地圖自帶一套、replan 金色、印刷對。精神一致但 token 從未統一；index 內其實已有明文的量化設計紀律（字階/按鈕三高/圓角三級），只是散落且未被其他表面繼承。
2. **318KB 單檔＋innerHTML 整塊重建**是脆弱性病根：狀態存 DOM 重繪即丟、永生元素被重繪換掉、快取被版號誤砍——git 病歷俱在。
3. **資訊架構是長出來的不是設計出來的**：replan 是趕工獨立頁、三個主要頁面互不連結、複習流程整個活在紙上而紙本試跑證實排程環節斷裂。

## 目標（依優先序）

- **G1 一套設計系統**：單一語意 token 架構（色彩/字階/間距/圓角/元件三態/動效語彙），全站四個表面（app、兩張地圖、新複習模組）共用；氛圍語系存活、強度隨模式收放。
- **G2 資訊架構重整**：三模式保留但入口與互連重設計；replan 併入工作台；地圖從 app 可達；「今日複習」條進工作台與待辦同位階。
- **G3 結構可維護**：單檔拆 ES modules、「狀態不存 DOM」紀律成文、!Boring 與死代碼清除、省電機制隨氛圍收斂而簡化。
- **G4 可重用工作流程**：整條路沉澱為 `/重設計` skill（vanilla＋React 雙軌）。

## 非目標

- 不換框架、不加建置步驟（ADR-0001）
- 戰功子系統不重寫（ADR-0003）
- 除「今日複習」與 replan 併入外**零新功能**；地圖內容零改動
- 不動紙本 study-rules、不動資料管線（fetch_exams / NotebookLM / 字幕筆記）
- **唯一允許觸碰的原版側檔案**：`istudy-private-backup/tools/serve_media.py` 的 `merge_progress()`（T07 需新增 review 欄位合併規則，必須對服役中原版向後相容）
- 不做使用者帳號、雲端、行動 app
- **凍結例外（使用者解凍）**：T12 裝置管理（ADR-0007）、T07b 紙本匯入遷移門（ADR-0004 補遺）、T14 讀書模式結構重造（ADR-0008）

## 成功判準

- S1 全站任一畫面的色/字/距/角/動效皆可追溯到同一份 token 檔；grep 不到 !Boring 與 feb-skin
- S2 原版全部既有能力在 feb2 上可用（桌面 smoke ＋ `_febSelfCheck()` 通過；iPad 手動清單見 T10）。**例外＝非目標所列退役項**：!Boring、replan 獨立頁、review-sheet 紙本產生器
- S3 兩張地圖以新模板重 build 成功且內容 diff 僅限樣板層
- S4 「今日複習」完整迴圈可跑：到期浮出 → 點 pass/A/B/C → 下次日期正確（含壓縮與重設規則）→ /sync 合併
- S5 動效經 `/watch-ui` 錄影驗收；讀書模式在觸控裝置無 backdrop-filter、無無限動畫
- S6 `/重設計` skill 可在一個全新專案上照走（以本案為 worked example）

## 約束

- 離線硬需求；`python -m http.server` 可服全站；SW 快取策略與資料/版號分離
- iPad Safari（無 devtools、3GB 空間）是一級公民；rlog 必須存活
- 衝刺進行中（至 9/12），原版持續服役，feb2 在 8643 平行開發（ADR-0005）
- localStorage 鍵名是 /sync 契約，不可改名（CONTEXT.md）

## 執行紀律

UI 票（T03–T08）在同一 working tree 上**一律循序、不開平行 session**——三模式容器、外殼 CSS、sw.js SHELL_FILES 是共用檔。每張 UI 票的驗收都含「本票新增/改名檔案已同步進 SHELL_FILES」。
