# T07 今日複習模組（本輪唯一新功能）

blocked-by: T05　｜循序原則：與其他 UI 票不得平行

## 目標
間隔重複排程數位化（ADR-0004）：工作台「今日複習」條——到期卡浮出
（卡號＋科目＋GoodNotes 頁碼），點 pass 或 A/B/C 失敗碼，下次日期自動排。

## 規格（權威原文在 `docs/reference/review-sheet-retired.html`，先讀它）
- 間隔 +3/+14/+28 天；距考 60 天內壓縮（+3/+7/+14）、30 天內（+2/+5/+7）——
  **壓縮檔位以「複習當日」距考日判定**，考期取自既有 feb-set
- 失敗（A/B/C 任一）→ 間隔重設回 +3；A=概念 B=流程 C=粗心，分布自動統計
- **「晚了不補」的精確語意（釘死，勿自行詮釋）**：過期卡仍顯示在今日（單一實例，
  不堆疊補課）；處理後下次間隔**從處理日起算**。例：卡 8/29 到期、8/31 才開站 →
  顯示；點 pass → 下次＝8/31＋14，不是 8/29＋14
- nextDue 落在考期之後 → 不再排（卡畢業，仍可查）
- 卡片建立：手動輸入卡號/科目/GoodNotes 頁（表單極簡，鍵盤可完成）
