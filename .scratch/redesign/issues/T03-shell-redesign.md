# T03 外殼重設計：待機畫面、模式機、頂欄、設定面板

blocked-by: T01, T02　｜循序原則：與其他 UI 票（T04–T08）不得平行

## 目標
以 tokens.css 重做三模式外殼：home 待機（時鐘/倒數/**天氣徽章**/入口）、模式切換轉場、
頂欄導航（含新增的地圖入口——三頁互不連結的現況在此終結）、設定面板。

## 做法要求
- 讀 ADR-0002 設計裁量：home 保留氛圍門面；study 進場即安靜；exam 居中
- **天氣子系統與晝夜明文保留**：即時天氣徽章、data-wx 七種天氣層、feb-geo/open-meteo、
  .day 晝夜（自動/日/夜）——全部留、重新調成新語彙；study 模式下天氣層隱藏（安靜化）
- 背景主題以 T01 使用者拍板的存活清單為準；feb-bg 存了已移除主題的舊值時
  fallback 到預設、不噴錯
- 液態轉場與漣漪：**預設留用**，把時長/曲線校到 token；只有違反 S5（觸控 backdrop-filter/
  無限動畫）或 design-system.html 明文規範時才換，且只能在既有動效語彙內替換，不新造效果
- 省電機制依新強度規範收斂（能刪的無限動畫刪，剩的保留凍結邏輯）

## 驗收
三模式切換、設定面板全功能；**6 種手動天氣＋晝夜三態切換可見生效**；
la-map/me-map 從頂欄可達（有網情境）；本票新增/改名檔案已同步進 SHELL_FILES；
/watch-ui 錄轉場與 boot 動畫，**幀圖貼給使用者、使用者回 OK 才算過**
（硬性項＝S5 兩條：觸控無 backdrop-filter、study 無無限動畫）。
